S. Lalith Kumar — Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, resume, and contact information as a Web Developer.


🌐 Live Demo

Portfolio: https://lalithkumar1801.github.io/ProStackHub_portfolio-website/


📌 About the Project

This portfolio website was developed as part of my Web Development internship at ProStackHub.

The website provides a simple and responsive way to showcase my technical skills, projects, resume, and professional profiles. It was built using core web technologies with a focus on clean structure, responsive design, accessibility, and user-friendly navigation.


✨ Features

Responsive design for desktop, tablet, and mobile devices
Fixed navigation bar with smooth scrolling
Hero section with introduction and call-to-action buttons
About Me section
Technical Skills section
Project showcase with Live Demo and GitHub links
Resume section with viewable PDF
Contact section with Email, LinkedIn, and GitHub links
Mobile navigation menu
Hover effects and UI animations
Semantic HTML structure
Deployed using GitHub Pages


🛠️ Technologies Used

HTML5 — Page structure and semantic markup
CSS3 — Styling, responsive layouts, animations, and hover effects
JavaScript — Mobile navigation and interactive functionality
Git & GitHub — Version control and source code management
GitHub Pages — Website deployment

🚀 Getting Started

1. Clone the repository
git clone https://github.com/lalithkumar1801/ProStackHub_portfolio-website.git
2. Navigate to the project
cd ProStackHub_portfolio-website
3. Open the website

Open index.html in a web browser.

For development, the project can also be opened using a local development server such as Live Server.
